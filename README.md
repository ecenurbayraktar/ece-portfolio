# Ece Nur Bayraktar Portfolio

Static portfolio website prepared from the provided CV.

## Files

- `index.html` - the complete portfolio page
- `assets/portfolio-hero.png` - generated hero image
- `assets/Ece_Nur_Bayraktar_CV.pdf` - downloadable CV

## Free Hosting Options

### GitHub Pages

1. Create a public repository, for example `ece-portfolio`.
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open repository `Settings > Pages`.
4. Select `Deploy from a branch`, choose `main`, then `/root`.
5. Your site will be published at a free `github.io` address.

### Netlify

1. Go to Netlify and choose `Add new site`.
2. Drag and drop this `outputs` folder.
3. Netlify will publish the static site on the free plan.

### Vercel

1. Import a GitHub repository containing these files.
2. Keep the framework preset as `Other`.
3. Deploy on the free Hobby plan.
