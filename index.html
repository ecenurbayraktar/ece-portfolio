Local RAG Assistant - Private AI for Your Documents

Local RAG Assistant turns a folder of PDFs into a private, searchable knowledge base. Users ask questions in English or Turkish and receive grounded answers with page-level references, without sending sensitive documents or prompts to a cloud API.

  • Built a complete desktop RAG pipeline: PDF extraction, chunking, embeddings, hybrid retrieval, prompt construction, local inference, and cited answers.
  • Combined semantic similarity with BM25 keyword scoring so the system understands meaning without losing exact names, numbers, and technical terms.
  • Ran Phi-3.5 Mini through Foundry Local, keeping document processing and answer generation on the user's Windows computer after initial model setup.
  • Designed a polished PySide6 interface for multi-document upload, conversational search, source inspection, and practical everyday use.
  • Added retrieval evaluation and regression tests to improve answer quality and make the AI workflow measurable, not just impressive in a demo.

STM32 Command Recognition - Embedded AI Experiment

The internship report shows a staged embedded workflow: CAN and STM32 fundamentals, GPIO/UART/ADC practice, HAL-based development, and a low-resource AI experiment for command or voice-based detection on STM32 hardware.

  • Built the foundation with STM32CubeMX configuration, HAL drivers, GPIO, UART serial monitoring, and ADC sampling.
  • Prepared command or speech data, extracted frequency-domain features, and compared model approaches such as CNN and RandomForest.
  • Converted a trained model through X-CUBE-AI and integrated it into STM32 firmware for on-device inference experiments.
  • Used LED feedback and console output to validate predictions, while noting accuracy limits caused by noisy input, small datasets, and hardware constraints.
